# صور المصحف — ختمتي

أرشيفات صفحات المصحف التي تنزّلها إضافة **ختمتي** لمحرّر VS Code عند الطلب.

المستودع لا يحتوي على الصور نفسها؛ فهي منشورة كأصول في صفحة **[Releases](../../releases)**.

## المحتوى

أربع روايات، **604 صفحة** لكلٍّ منها، مرقّمة بأصفار بادئة (`001` … `604`).

| الأرشيف | الرواية | الصيغة | الحجم |
|---|---|---|---|
| `hafs.zip` | حفص عن عاصم | JPEG | ‎151 م.ب |
| `warsh.zip` | ورش عن نافع | WebP | ‎113 م.ب |
| `qaloun.zip` | قالون عن نافع | WebP | ‎119 م.ب |
| `douri.zip` | الدوري عن أبي عمرو | WebP | ‎131 م.ب |

الصيغة تختلف بين الروايات، وهذا مقصود: كلٌّ منها صُدِّر بالصيغة التي تحفظ جودة أصله. القارئ يقرأ امتداد كل ملف كما هو ولا يفترض صيغةً بعينها.

كل أرشيف يفكّ إلى مجلد باسم الرواية:

```
hafs/            warsh/
  001.jpg          001.webp
  002.jpg          002.webp
  …                …
  604.jpg          604.webp
```

الأرشفة بلا ضغط (`store`) لأن JPEG و WebP مضغوطان أصلًا، فإعادة ضغطهما تستهلك وقتًا دون توفير يُذكر.

## التحقق من سلامة التنزيل

مع كل إصدار ملف `checksums.txt` يحوي بصمات SHA-256:

```bash
sha256sum -c checksums.txt
```

الإضافة تتحقّق من البصمة قبل فكّ الأرشيف، فالتنزيل المقطوع يُرفض بدل أن يُنتج صورًا تالفة.

## تخطيط الصفحات

الروايات الأربع في هذه المجموعة **متطابقة في حدود الصفحات**: الصفحة نفسها تحمل النصّ نفسه في الأربع، ويختلف الرسم وترقيم الآيات والزخرفة فقط. لذلك تكفي خريطة سور وأجزاء واحدة لها جميعًا.

ملاحظتان على الصور: الصفحة الأولى لوحة مزخرفة للفاتحة بلا رقم مطبوع ولا ترويسة، ورواية قالون تطبع **الحزب** (1–60) في الترويسة بدل الجزء (1–30).

## الإصدارات

وسم الصور مستقلّ عن وسم الإضافة (`mushaf-v1` مقابل `v0.1.0`)، حتى يمكن تحديث أحدهما دون الآخر.
